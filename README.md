# 美股情报台

独立于「知量研究学院」的美股市场事件网站。默认展示过去 12 小时的财报、宏观、公司、政策和行业新闻，可切换 3 小时或 24 小时、按类别与关键词筛选。

标题自动翻译为中文，并尽量在标题下保留公司英文名、股票代码和 CPI、FOMC 等专有名词。点击任何新闻条目可打开英文原始报道。翻译与重要度标签均由程序自动生成，应以原文为准。

GitHub Actions 每 15 分钟尝试从公开新闻 RSS 与美联储官方 RSS 抓取并重新部署。网页每 5 分钟检查一次新数据，显示数据更新时间；外部来源或定时任务可能延迟。翻译使用公开接口，若翻译失败，当前更新会保留上次成功部署的数据。无需 API 密钥。

本地预览：`python3 -m http.server 8000`，然后访问 `http://localhost:8000/`。

本地更新：`node scripts/update_market_news.mjs`。该脚本需要网络及系统安装的 `curl`。
